# Вклад в шаблон создания (Русский)

> [English](../../contributing/templates-contributing.md) | [简体中文](../../zh/contributing/templates-contributing.md) | [日本語](../../ja/contributing/templates-contributing.md) | [한국어](../../ko/contributing/templates-contributing.md) | [Bahasa Indonesia](../../id/contributing/templates-contributing.md) | [Español](../../es/contributing/templates-contributing.md) | [Français](../../fr/contributing/templates-contributing.md) | [Deutsch](../../de/contributing/templates-contributing.md) | [Português](../../pt/contributing/templates-contributing.md) | **Русский** | [العربية](../../ar/contributing/templates-contributing.md)

Шаблон создания — это папка внутри [`template/<модуль>/<id>/<версия>/`](../../../template/) с файлом `template.json` и локальными ресурсами. Шаблоны питают визуальные селекторы генерации изображений, видео и обложек — пользователи начинают с вашего пресета, а не с пустого промпта. Это руководство объясняет, как добавить шаблон.

---

## Что шаблон создания ЕСТЬ / чем НЕ является

**Шаблон ЕСТЬ:**
- Настроенный пресет: промпты по умолчанию, стилевые подсказки, настройки соотношения/длительности/качества, плюс обложка и превью, показывающие результат.
- Самодостаточный. Всё, что показывает селектор, находится в папке шаблона.

**Шаблон НЕ является:**
- Новым *типом* шаблона. Текущие модули — `image-generation`, `video-generation` и `cover-generator`. Если вам нужен новый модуль, сначала откройте issue для обсуждения — это изменение продукта, а не шаблон.
- Свалкой промптов. Шаблоны с пустым или общим промптом и без локализованных значений по умолчанию будут возвращены; ценность — в настройке.
- Чужой работой без прав. См. [Атрибуция и права](#атрибуция-и-права).

## Быстрый старт

```bash
corepack enable && pnpm install
cp -r template/cover-generator/images-go-hard-thumbnail template/<модуль>/<id-вашего-шаблона>
# отредактируйте template.json, замените ресурсы обложки/превью
pnpm templates:validate     # должен пройти до открытия PR
```

ID шаблонов — строчные буквы через дефис, уникальны внутри модуля. Версия начинается с `1` — одна папка на версию, поэтому обновления создают `<id>/2/`, а не редактируют `<id>/1/`.

## Анатомия папки

```
template/<модуль>/<id>/1/
├── template.json        # обязательно: метаданные, значения по умолчанию, локализованный контент
├── cover.jpg            # обязательно: показывается в селекторе шаблонов
├── preview.jpg          # модули изображений/обложек: увеличенное превью результата
├── previewVideo         # модуль видео: пример клипа, напр. example.mp4
└── author-avatar.jpg    # необязательно: аватар указанного автора
```

## Поля template.json

| Поле | Обязательно | Примечания |
|---|---|---|
| `schemaVersion` | да | Сейчас `1`. |
| `id`, `version`, `module` | да | Должны соответствовать пути папки `<модуль>/<id>/<версия>/`. |
| `runtimeTemplate` | да | Соответствие исполнителю Runtime, напр. `{"id": "cover", "version": 2}`. Скопируйте из шаблона того же модуля. |
| `status` | да | `published` для публикации; используйте `draft` во время доработки. |
| `title`, `description` | да | `zh-CN` и `en-US` обязательны. Другие языки необязательны. |
| `cover` | да | Относительный путь к миниатюре селектора. |
| `preview` / `previewVideo` | зависит от модуля | `preview` для изображений и обложек, `previewVideo` для видео. |
| `defaults` | да | Базовые настройки, с которых начинает пользователь (промпт, соотношение, длительность, качество…). |
| `defaultsByLocale` | настоятельно рекомендуется | Локализованные переопределения промпта и стиля по языкам. Именно здесь живёт настоящая настройка — см. ниже. |
| `tags` | рекомендуется | Метки для поиска; держите их фактическими. |
| `author` | если применимо | `name`, `url`, `avatar` для указанных внешних источников. |
| `featured`, `sortOrder` | нет | Оставьте `featured: false`; решение о продвижении принимают мейнтейнеры. |

## Промпт — это и есть продукт

Ревьюеры проводят бо́льшую часть времени с `defaults` и `defaultsByLocale`:

- **Оба языка должны быть настоящими промптами**, а не переводами, потерявшими настройку. Промпты `zh-CN` и `en-US` должны давать эквивалентные результаты, используя сильные стороны каждого языка.
- **Параметризуйте то, что должно меняться.** Если заголовок или объект редактируются пользователем, скажите об этом явно в промпте (существующие шаблоны используют маркеры вроде "Customizable text: …").
- **Формулируйте ограничения.** «Без водяных знаков, без лишнего текста, без лишних людей» — негативные ограничения так же важны, как описание, для воспроизводимых результатов.
- **Соответствуйте структуре `defaults` модуля.** Шаблоны изображений несут ratio/candidateCount/quality; видео — size/duration; обложки — заголовок, язык текста и поля стиля. Скопируйте структуру из существующего шаблона вашего модуля.

## Ресурсы

- Сгенерируйте `cover.jpg` и превью **самим шаблоном** — стоковое изображение или несвязанная графика будет отклонена.
- Держите размеры файлов умеренными; эти файлы поставляются с приложением и загружаются в селекторе.
- Превью должно показывать *типичный* результат, а не лучший из пятидесяти вариантов.

## Атрибуция и права

Если ваш шаблон адаптирует чужой опубликованный промпт или стиль:

- У вас должно быть право на его распространение.
- Заполните поле `author` значениями `name` и `url` (и `author-avatar.jpg`, если доступно), как это делают существующие шаблоны.
- Если сомневаетесь, откройте issue и спросите до начала работы.

## Критерии слияния

- [ ] Путь папки соответствует `id`/`version`/`module`; ID уникален в модуле.
- [ ] `pnpm templates:validate` проходит.
- [ ] `title` и `description` предоставлены на `zh-CN` и `en-US`.
- [ ] `defaultsByLocale` содержит настроенные промпты для обоих языков.
- [ ] Ресурсы обложки и превью сгенерированы самим шаблоном.
- [ ] Атрибуция `author` включена при адаптации внешней работы.
- [ ] `featured: false`, `status: "published"` (или `draft` с пометкой в PR).

## Частые причины отклонения

- **Общий промпт** — шаблон ничего не добавляет к пустому промпту; селектор в нём не нуждается.
- **Отсутствующий язык** — настроен только один язык, или машинный перевод потерял стилевые ограничения.
- **Несоответствие ресурсов** — обложка не соответствует тому, что промпт реально генерирует.
- **Непонятные права** — адаптация чужой работы без атрибуции или разрешения.
- **Старая версия отредактирована на месте** — создайте новую папку версии вместо перезаписи истории `<id>/1/`.
