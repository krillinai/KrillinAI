# 下拉菜单统一验收（2026-10-23）

## 范围与实现

本次属于 P1 共用 Web 界面交互调整，不涉及 Runtime、协议、数据库、价格或服务部署。

- 新增 `components/forms/Select.tsx`，所有原生单选入口及已有 `NativeSelect` 调用统一使用主题化菜单。`NativeSelect.tsx` 保留兼容导出，不再呈现系统菜单。
- 覆盖音色语言、性别、风格和场景筛选，以及创作参数、字幕设置、产物版本、项目、定时任务、设置及初始配置中的原生下拉入口。已采用专用主题组件的模型、语言和音色菜单继续使用原组件。
- 菜单沿用主题的背景、边框、阴影、悬停和重点色；较长列表可搜索，选中项显示勾选。菜单限高滚动，并根据窗口边界向上展开或调整水平位置。
- 支持方向键、Home / End、Enter、Escape 和 Tab；跳过禁用选项，选择后恢复焦点。嵌套音色弹窗中的菜单不会误关外层弹窗。
- 保留实际表单值、受控与非受控状态、重置和原有 `onChange` 事件；内部原生控件仅隐藏用于表单兼容，不可通过页面操作打开。
- 两处原生 `datalist` 入口改用共用 `SuggestedInput`，保留自由输入和推荐值选择。静态扫描确认生产 Web 源码已无可见原生 `select` 或 `datalist` 入口。

## 验证

- 22 个相关测试文件共 427 项通过，包含共用菜单、模型自由输入、音色筛选、图像与视频参数、字幕编辑、项目与设置等；Web 类型检查和差异检查通过。
- 对涉及改动的更大范围回归共检查 525 项。DashboardPage 中 19 项视频翻译旧流程测试、VideoDownloadWorkspace 中 1 项阿拉伯语字幕文案测试原本已失败；使用临时原生控件替代实现复核，失败项完全相同。未扩展修复这些既有问题；临时基线文件已清理。
- 真实浏览器验收：音色风格下拉显示深色菜单和搜索框，搜索“温暖”并选择后正确显示 4 / 28 个音色，仍保留所选 eve；设置页默认权限菜单展示相同主题、选中标记及正确的相对位置，验收中未更改权限。
- 未调用付费模型或生成音频。没有重启服务；运行中的开发页通过热更新生效。本轮未打包或发布新的 Desktop 安装包。
