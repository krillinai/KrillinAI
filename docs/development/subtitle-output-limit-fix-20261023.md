# 字幕翻译输出额度修复（2026-10-23）

## 原因和修复

字幕翻译使用的响应预算可以超过当前模型的 4096 token 上限。Gateway 在预占积分、调用模型之前返回 HTTP 400；同一批次结束时其他并行请求被取消，本地仍出现两条接受状态未知的记录。

Gateway 公开目录新增可选 `textOptions.maxOutputTokens`，直接读取数据库模型修订中的输出上限。Daemon 从当前任务绑定的目录读取该字段，传入每次执行生成的临时 Runtime TOML，不新增持久配置副本。翻译引擎按模型上限分批、预留 1024 token 余量，所有请求和预算扩张均受模型上限约束；未提供上限时保持原有默认行为，自定义 LLM 覆盖不继承官方限制。

明确拒绝的 HTTP 响应优先记为失败，响应中的追踪编号不再使其变为接受状态未知。超时、连接断开及查询不到的其他请求继续保留原有防重复扣费保护。
