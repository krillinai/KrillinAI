# 任务独立模型选择检查（2026-10-23）

## 行为约定

设置页保存账户默认模型。任务开始配置时继承对应默认值，用户在任务内的选择保存到该任务的 `state.officialModels`，执行时优先使用任务选择。更换账户默认值不会覆盖已保存的任务选择。

模型目录继续来自 Gateway，不新增配置文件、独立模型表或前端静态型号清单。本次补齐的是客户端选择入口和任务配置读取链路。

## 本次修复

- 统一复用现有可搜索模型下拉框，目录和可用状态来自 Gateway；字幕相关识别选项仅展示支持时间戳的模型。
- `useOfficialServices` 每次仅写入该字段对应的模态，避免显示一个字段时隐式填入其他模态的第一个可用型号。
- `CreatorSessionProvider.updateDraft` 根据最新草稿合并 `officialModels`，防止多个模型字段同时初始化时覆盖彼此。执行动作仍先保存草稿，再启动阶段。
- 已保存任务选择优先于账户默认值；运行中及有排队阶段时锁定模型选择。模型失效时保留已选值，要求明确重选，不静默替换。
- 视频翻译结果更换翻译模型或识别模型后，会出现重新翻译入口；必须点击确认才提交执行。仅更换翻译模型可沿用原版本输入，更换识别模型则不沿用原版本的识别结果。
- 翻译版本记录的 `officialModels` 用作型号比较依据，不额外持久化第二套价格或模型配置。没有型号记录的旧结果使用本次页面会话的比较基准，打开页面或等待目录加载本身不会请求重新翻译。
- 火柴人工作流的图片、配音调度与执行共同使用任务配置，保留未提供任务读取器时的旧接口回退。

## 兼容边界

未修改 Gateway、数据库结构或已有客户端请求协议。缺少 `officialModels` 的旧任务继续使用原服务绑定及配置回退；保留旧任务已有字段，不批量改写历史任务。新增入口需要使用包含本次 Web 代码的客户端，本次未发布客户端安装包。
