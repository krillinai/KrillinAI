## What's New

- Improved the video translation workflow with clearer stage progress, subtitle editing, live composition previews, and smoother rendering and download steps.
- Made subtitle translation more resilient with sentence-level checkpoints, recovery of incomplete translations, and improved subtitle timing and line wrapping.
- Improved translation model selection and added direct HTTP requests for API-key text providers, allowing local subtitle translation without starting a Codex runtime.
- Improved media downloads with parallel source retrieval and support for resuming interrupted downloads.
- Refined shared model selectors, model-specific controls, and voice library interactions across Creator workspaces.
- Updated the default OpenAI image model to gpt-image-2 and migrated saved gpt-image-1 settings while preserving independently configured models.
- Fixed parallel tool calls from Chat-compatible providers being combined when streamed chunks omit tool indexes.
