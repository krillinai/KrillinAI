## What's New

- Video translation now prioritizes available source subtitles and defers full-video downloads until video composition or source-video preview is requested.
- Added on-demand source-video downloads for saved translation results, with visible download progress. Existing subtitles, edits, and result versions are preserved.
- Fixed preview flickering and playback resets caused by workspace updates or language switching.
- Fixed Bilibili multipart links so the selected part is preserved throughout metadata lookup, downloads, and translation. Multipart videos now require part selection instead of accidentally downloading an entire collection.
- Added platform-aware local Whisper component management, including engine versions, model status, and download progress. When transcription requires missing components, tasks show preparation progress and continue automatically after installation.
- Fixed local Codex image generation with ChatGPT sign-in and improved authentication and readiness guidance for both sign-in and API-key configurations.
- Improved Creator Runtime connection recovery, including bounded Desktop service recovery, actionable diagnostics, and draft preservation without automatically resubmitting tasks.
- Added support for configurable FunASR/SenseVoice transcription services.
- Expanded video source languages with French, Spanish, Italian, Portuguese, Indonesian, and Thai. Fixed Thai short-subtitle generation and improved handling of conversational text and trailing commas in LLM JSON responses.
- Improved Creator template browsing, filters, detail descriptions, and visual presets.
- Added configurable Aliyun OSS regions and endpoints.
- Added Chinese, English, and Swedish copy for the updated translation, component-management, progress, and diagnostic interactions.
