## What's New

- Added Volcengine ASR and TTS support for video translation, including official voice catalogs and shared Access Token configuration.
- Added Creator preflight checks that surface missing services, invalid configuration, and unavailable Runtime capabilities before a task starts.
- Refined the Dashboard, project and output center, settings, and Creator workspaces with denser layouts, consistent page boundaries, and improved native controls.
- Improved macOS Desktop window integration with functional close, minimize, and zoom controls, synchronized light and dark appearance, and the real application version in About settings.
- Replaced the Xcode 26 adaptive icon build with a cross-platform 1024 px application icon, so local macOS packages no longer require the full Xcode installation.
- Improved packaged template media streaming, YouTube cover input handling, settings return navigation, and Runtime component status refresh.
- Streamlined CI and Desktop release promotion with parallel verification, targeted packaged App smoke tests, split caches, and reusable candidates bound to deterministic build inputs.
