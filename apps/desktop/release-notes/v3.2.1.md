## What's New

- Introduced the new Creator template workspace with workflows for image generation, video generation, article writing, Xiaohongshu copy, and short-form video scripts.
- Added a smart video clipping workflow with controls for content focus, target duration, clip count, and output aspect ratio.
- Added support for importing existing SRT subtitles into video translation, with improved subtitle timelines, media reuse, and failure recovery.
- Improved OpenCreator Agent and model service configuration, including better compatibility with DeepSeek, custom OpenAI-compatible services, and multiple providers.
- Configuration errors now identify the invalid field and display the underlying Runtime error.
- Improved Creator task progress, artifact version management, template resources, and Desktop stability.
- Replaced the image parsing dependency affected by a high-severity denial-of-service risk; template image dimensions are now validated with Sharp.
