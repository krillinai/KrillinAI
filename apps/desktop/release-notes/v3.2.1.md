## 更新内容

- 上线全新的 Creator 模板工作台，新增图像生成、视频生成、文章写作、小红书文案和短视频脚本等创作流程。
- 新增视频智能切片工作流，支持内容重点、目标时长、切片数量与输出画幅配置。
- 视频翻译支持导入已有 SRT 字幕，并优化字幕时间轴、媒体复用与异常恢复。
- 优化 OpenCreator Agent 与模型服务配置，增强 DeepSeek、自定义 OpenAI 兼容服务及多 Provider 的兼容性。
- 模型与代理配置保存失败时，现在会定位具体字段并显示 Runtime 返回的真实原因。
- 改进 Creator 任务进度、产物版本管理、模板资源和 Desktop 稳定性。
- 移除存在高危拒绝服务风险的图片解析依赖，模板图片尺寸校验改用 Sharp。
