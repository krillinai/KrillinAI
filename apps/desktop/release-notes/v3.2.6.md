## What's New

- Connect an OpenCreator account to use official model and media services, view credit balances, and manage account settings.
- Simplify the personal center and open the website for subscriptions and credit purchases, with payment status refreshed when returning to the app.
- Show sign-in status promptly after browser authorization and allow signing in or out while tasks are pending.
- Connect YouTube through an existing Chrome profile and save its login session for video downloads and translation.
- Fall back to Whisper transcription when platform captions are unusable and show the fallback reason in task progress.
- Bundle a JavaScript runtime for yt-dlp to improve YouTube download compatibility.
- Update runtime dependencies and fix high-severity dependency audit findings.
