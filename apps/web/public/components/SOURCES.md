# Runtime component logos

These assets identify third-party components in Settings. All images are served locally.

- `whisperkit.png`: Argmax's GitHub organization mark, the maintainer of WhisperKit. Source: https://github.com/argmaxinc.png?size=256
- `remotion.png`: Remotion's official documentation favicon. Source: https://raw.githubusercontent.com/remotion-dev/remotion/main/packages/docs/static/img/favicon.png
- `yt-dlp.png`: Converted from the official project's 256 x 256 ICO using macOS `sips`. Source: https://raw.githubusercontent.com/yt-dlp/yt-dlp/master/devscripts/logo.ico
- `whisper-cpp.png`: ggml's GitHub organization mark, the maintainer of whisper.cpp. Source: https://github.com/ggml-org.png?size=256
- `faster-whisper.png`: SYSTRAN's GitHub organization mark, the maintainer of faster-whisper. Source: https://github.com/SYSTRAN.png?size=256
