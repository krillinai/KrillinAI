# 字幕共享语境与术语一致性

本轮针对跨批次概念漂移：同一视频中的距离缩写不应先译成公里、随后又变成步数。保留现有预分句、原译覆盖校验、时间映射及断点恢复，不加入配音或配置选项。

## 流程

1. 按完整父句（超长时为模型预算保护后的语义段）组织原文，NLP片段仅作为父句内部的显示边界建议，不生成独立翻译ID。将全部父句按实际 JSON 大小划成连续章节，每章最多6500字节、64句。章节是请求预算单位，不代表已识别场景或角色。
2. 每章生成最多600字节的语义摘要及12项重点术语，优先数字单位、歧义缩写和专名。术语包含原词、推荐译法、语境含义及适用句子ID；逐一核对ID、原文出现位置、重复与长度，不接受无证据的术语。某个适用ID无原文证据时只移除该ID，保留其余有效术语与章节摘要；同一词在同一位置出现冲突释义时，两项均不采用，不任意选一项。
3. 长视频按请求预算分层汇总全部章节摘要；不截取视频开头冒充全片摘要。批次携带共享主题、所在章节摘要和仅适用于当前句子的术语。请求预算不足时优先省略摘要，保留术语并缩小批次。单句仍超预算时跳过该句的额外语境并记录提示，译后仍用完整计划审校术语，避免可选语义步骤阻止原有翻译。
4. 内容初译只发送完整父句、一次批次前后文、主题和适用术语；不发送NLP边界、长度参数，不要求回显原文或配对。按已有批次大小与请求/响应预算合批，不再强制每批最多3句。只重试失败ID。默认随后对完整译文作一次语境、术语、含义和自然度修订，只返回必要改动；改动另外对照原文独立核验，成功后不重复术语专项审校。允许目标语言的词形变化和同义表达，不用字面替换执行翻译。对比用单轮模式仍保留有证据术语的专项检查。
5. 内容翻译与冻结排版分别合批。排版不重复发送主题、术语与批次上下文，仅消费完整父句、冻结译文及边界提示；短单段由本地直接配对。修改以整句完整译文为单位；原分段作废。放得下时直接保留一对，超长时只对该句重新排版并锁定新译文。排版故障时保留完整修正内容，不能删字以满足长度。

## 音频转录路径

多音频片段先完成全部转录，再按音频原顺序整理全片语境。NLP对所有父句批量处理一次，边界建议和术语适用句子ID随后映射回每段的局部父句ID，原有片段时间定位、翻译产物与进度接口保留。翻译仍在片段内部按批并发。

这会推迟长视频开始翻译的时间，并取消此前转录与翻译的重叠执行；需要完整转录才能利用后半段证据。原文识别本身、配音以及视频提取能力不在本轮范围内。

## 缓存和故障

语境和审校的成功响应按输入、提示词、模型、接口地址原子缓存到任务目录的 `translation-semantics`。完整语义计划及审校提示词进入翻译内容指纹；改变语义计划会产生新的句级检查点，改变字幕显示长度或批次大小仍可复用完整译文。

尚未完成审校的译文也会落盘，并以 `semantic_reviewed` 区分完成状态。恢复任务时复用完整译文，只补缺失的审校，不重复翻译。

新增语义步骤每次只请求一次；接口失败、非法JSON或证据校验失败时保留已有翻译能力并记录提示，不将未完成的术语审校标记为通过。取消始终中止任务。全片摘要生成失败时仅提供可用章节语境，避免把部分内容标为全片理解。

## 验证边界

定向测试覆盖术语证据、同词不同含义、非英语和无空格语言的匹配、视频后半段覆盖、音频乱序转录的全片语境、修正译文锁定、缓存、取消和故障恢复。模型对主题与词义的推断仍需真实样本核对；结构和原文证据检查不能证明所有语义判断正确。

本轮不会自动修复字幕块被压平后丢失的抢话关系；该问题需要独立保留原始对白边界。

## 完整译文修订

生产构造默认开启完整译文修订，不新增用户配置。基准构建可以通过`translationRevisionDefault`选择单轮对照流程。修订阶段只返回需要修改的句子及完整新译文，不重写正确句子；改变后必须另外对照原文核验事实、专名、数字、否定、程度、条件、时间与因果，再进入冻结排版。修订检查已包含语境和术语，成功后不再发出一轮重复的术语检查。独立核验只发送实际改动句子、批次上下文及适用术语，不重复全章摘要。

原始初译保存在`draft_target_text`，成功修订保存`revision_version`指纹；恢复时不重复已完成修订。审校请求不发送这些本地元数据。修订未通过核验时保留初译并报错，不能标记为修订成功。目标语自然度、专名遗漏及分段对应仍须用真实字幕评阅，增加修订阶段本身不保证质量改善或token减少。

同批修订独立按ID核验、保存：已通过的改动和无需修改的父句立即持久化，仅被拒绝的改动进入剩余重试预算；不能因一个失败项重做同批成功项。核验结合原文和上下文理解口语省略、自我修正与明确指代，允许等义转述；拒绝时应指出具体改变、遗漏或添加的含义，不能仅因译文用了原文没有的字面措辞而否决。事实、限定、角色与逻辑检查仍保留，无法确认时不接受。
