# 音频/VTT冻结排版实现与评测

本次在`8907991e025e44e88dc4f446b9e113ec47f9c572`上修复排版改坏原译及长度回退超限的问题。英译日312个完整译文、日译英288个完整译文全部保留，最终原文和译文均不超过60显示单位。阅读节奏和上游翻译质量仍有已知问题，不能据此宣称质量全面提升或超过VideoLingo。

## 实现范围

- 仅音频/VTT语义翻译入口启用冻结排版版本9；原始SRT导入沿用旧策略，初译和内容校准策略保持既有实现。
- 内容校准后保存`layout_base_target`；模型排版和边界审校只允许切分边界，不得增删、改字或调序。
- 排版最多两轮模型边界建议，`layout_attempts`保存在句级检查点中。只补做失败单元，恢复时不重置已用预算。
- 模型不可用或建议失效时，由程序结合Unicode词/字素边界、可选本地NLP词块与依存成本和长度均衡选择切口。优先局部调整，必要时比较一次完整句布局，不重译。
- 原文和译文每条分别受配置硬上限约束，换行不能绕过计数；双语以完整句保证整体对应，允许不同语序的信息分布到相邻小条。
- 程序布局记录`layout_approximate`，与模型审校成功区分。完整译文和布局状态分别保存；旧排版可能改写过全文且没有冻结基准时，复用保存初译重新校准，不将旧改写冒充校准原译。
- 音频`TranslatedItem.DisplayGroupSize`保存完整句显示分组，检查点恢复后导出仍生效。优先保留词时间，必要时只在当前完整句范围内重新分配显示时段。
- 导出检查两侧长度、非空、正时长和不重叠。无法满足基本约束时保留检查点并明确报错；不通过超长合并或跨句借时间隐藏问题。

60显示单位约为30个全角字符，空格、标点和混合英文同样计宽；不等于字体像素宽度。对字序与字素的保护不保证所有技术名称或语义切口最优。
