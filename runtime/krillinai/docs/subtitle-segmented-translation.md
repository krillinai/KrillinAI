# 以意群为结构的字幕翻译实验路径

本路径独立于已有完整父句翻译、冻结译文排版流程。默认仍使用原路径；同输入的质量和消耗验收通过后再决定切换。仅涉及字幕，不涉及配音、下载、转录、配置页面或部署。

## 流程

1. 复用多语言源句预处理、NLP/语义分句和全片/章节语境。每个意群保存父句 ID、稳定分句 ID、源文 UTF-8 字节起止位置。
2. 一个父句的全部意群一起忠实初译。完整父句同时提供全文与其全部有序源文意群，便于重新核对关系。固定草稿对照未证明缩批有稳定收益，保留约 1000 个源文显示单位或 20 个意群的批次；单个完整父句超过预算时仍保持完整。批次只提供一份前后文、主题和按原文证据适用的术语；父句不会跨请求。
3. 表达阶段参考VideoLingo的具体 `origin/direct/reflect/free` 表：每个意群独立指出直译问题并生成意译，完整父句全文和有序ID仍共同提供。输出表用稳定意群ID作键，本地按输入顺序恢复父句，拒绝重复或未知键。源文位置不发送给模型；原文意义、角色、语气和术语仍受保护，这一步不承担长度约束。初次表达也允许显式合并最小连续语法块，不必先通过一次失败审查才能处理口语改口。
4. 本地验证 ID、顺序、覆盖、字素、词/专名保护、单行和目标语言。任一侧超过 75 显示单位时，有源语言模型时，优先从依存树的安全边界选择源文切口（保持短语完整、按自然连接与标点排序、满足75宽度）；无可用方案时才调用LLM选择切口。随后固定切口对齐已有译文，必要时自然改写局部译文。对齐任务不得改源文切口；完整父句以带 ID 的原译文配对提供，只读，避免局部补译重复邻段。有源语言模型时，切口额外检查冠词/形容词与名词、介词与宾语、助动词、近邻程度副词等依存边；失败先改切口，不交给译文对齐掩盖。预分句不在副词/功能词内部并列处分段。缺模型时明确沿用NLP降级，不能声称完成句法校验。LLM给出的合格源文切口原子缓存，恢复对齐时可复用；依存树选择是本地计算，不增加LLM请求。提供双侧实测宽度及分段参考；重试提高最少段数。实测反馈后若模型仍返回结构合法但有超长子段的配对，只保存为未审候选，保留有效分段，下一轮仅重拆超长子段；全部双侧合规后才审查，最多三轮，不机械截字。
5. 对最终候选统一作一次独立审查：完整含义、自然度、逐段对应，只返回已检查父句 ID 与具体失败项。超长重拆与普通翻译共享这次审核，避免审核即将废弃的布局后再审一次。检查完整父句，防止局部补译造成跨段重复或遗漏。
6. 失败父句回表达阶段并再次独立复核。NLP 若把废弃的口语修正或依存成分单独切出，初次表达和修复都可以显式合并最少相邻分句：`segment_ids:["8.2","8.3"]`；编辑表以第一项ID为键，不为已消费ID再输出独立条目。空译文不能作为隐式合并指令；只有本地按源语言确认完全由无语义犹豫音构成的片段可省略译文。初译仍不允许模型合并，缺失、重复、跳跃或乱序 ID 不补猜。代码按原文位置合并，保留 `source_segment_ids` 记录，合并后仍须独立核验含义和对应。合并导致超长时重新选择合规边界，最多三轮。

v9的对齐变化：实际源语言依存树最多提供三组完整候选，每组均通过原文覆盖、受保护文字、句法和75宽度检查。对齐可从这些候选中选择更适合目标语表达的一整组，不允许混拼或发明新源文切口；无模型时继续固定经验证的LLM切口。仅在对齐改变了译文时，保存该局部块的改前译文作为只读审查参考。审查分别核对自然表达与忠实/对应关系；同一父句可返回多条具体缺陷，本地合并全部原因与受影响ID，不因辅助分类名称或多条反馈而丢失问题。


软目标由现有调用参数提供，产品实验使用 65，硬上限固定为 75；宽字素簇计 2，其他计 1。不能用机械最短字数制造或消除短句，独立短回答可以短。该路径不调用旧完整修订、冻结排版、排版复核等链条。

## 协议和恢复

- 术语区分 `kind=name` 稳定身份专名与 `kind=context` 语境建议；缺省按建议处理。表达调用可返回带原文证据的 `term_decisions` 纠正候选译法，随父句持久保存。后续对齐与审查按父句覆盖旧建议，不污染其他父句或并行批次；不为每个词单独调用模型。决定字段仅接受无冲突的 `target`/`corrected_target`，持久化统一使用 `target`。这属于证据与协议校验，不能保证语义正确。
- 初译与对齐字段为 `direct` 或 `target_text`；接受无歧义的 `text` 别名，冲突字段拒绝。v9编辑表使用 `free`，内部转换为同一配对结构；仍兼容并严格检查旧结构化响应。编辑表反思只是模型建议，不能证明其修改有效。
- 仅缺结构结束符时可以本地补齐；不补文字、字段、值或分句，逐 ID 完整性检查仍生效。
- 状态包括 `source`、`faithful`、`expressive`、`repair`、`reviewed`，有效父句逐条原子保存。只发布独立审查通过且双侧不超长的字幕。
- 缓存指纹包含新路径版本、提示词、模型、端点、语言、原文、语境计划及填充词策略，与旧路径隔离。恢复时验证原文位置和覆盖，从已保存阶段继续；不信任旧排版审核标记；中日等无空格语言连接 cue 时，不在词内插入空格，嵌入的拉丁词仍保留必要分隔。
- 实验路径将最终采用的语境计划单独原子保存，包括摘要失败时的降级计划；同任务恢复沿用该计划，避免可选摘要重试成功后内容指纹变化、全片重译。读取时检查章节覆盖与术语原文证据，取消不写完成计划。此修复不追溯补造早期失败测试的缓存；早期额外成本全部计入实测。
- 时间轴继续使用已有原文覆盖和词级时间映射，不按中英文长度比例分配。
- NLP 模型未安装或语言不支持时明确记录降级，继续使用通用父句预处理、完整父句翻译和局部语义重拆，不能称其为该语言的句法模型验证。

## 运行调度与失败恢复

实验路径使用持续补位的并发队列：一个批次完成后立即领取下一批，不再等待同组最慢批次。检查点中未完成的父句与新父句进入同一队列，避免恢复阶段串行处理。并发上限沿用现有配置；遇到限流后，让在途请求收尾，后续只保留一个工作槽位。

模型格式和内容校验错误与接口、磁盘、取消错误分开处理。前者保留该批错误，让其他批次继续保存结果；阶段内重试后，最多再从已保存阶段续跑一次。仍失败则任务明确报错，不发布未审字幕。接口或磁盘致命错误、任务取消仍中止其他工作，不能把错误吞掉当成功。

只缺 JSON 结构结束符时复用有限封口逻辑，不补文字或猜测字段。生成阶段发生文本截断、输出预算不足或 JSON 结构错误时，将多个完整父句组成的失败批次二分；单个父句仍保持完整并受重试次数限制，已完成初译不会重做。源切口按条目保留合法候选，只将无解或失败 ID 交给下一轮模型；被拒切口及原因写入未完成父句检查点，恢复时继续排除，不能让一个坏候选丢弃其他合法结果。

每个翻译任务拥有一个常驻 Python NLP 进程，按实际源语言复用已加载的 spaCy 模型，用于分句、源切口候选和依存校验。访问串行化，单次调用含排队上限为 90 秒；异常或超时回收该进程，后续可重新启动，任务结束或取消时回收。调用的分句和依存算法保持一致，不在运行时下载模型；缺模型继续明确降级。任务之间不共享进程或语言状态。

这些调整不修改翻译 Prompt、不放宽双侧 75 硬上限、不跳过完整父句审查。新旧二进制、失败调用与真实运行耗时分别保留；缓存复跑只验证恢复正确性，不能作为速度成绩。

## 开发验证

内部构建开关，无新增用户配置：

```sh
go build -ldflags '-X krillin-ai/internal/service.translationFlowDefault=segmented' -o krillin-segmented ./cmd/cli
go test -race ./internal/service -run 'TestSegmented|TestSemantic' -count=1
```

测试覆盖父句共享语境、多语言 ID/位置、失败父句局部重试、含义复核、取消后阶段恢复、缓存隔离、相邻分句显式合并、缺括号的有限规范化以及超长重拆后的完整父句核验。真实模型输出的含义和自然度仍需单独评估，单元测试不能证明翻译质量。

实测证据保存在工作区 `benchmarks/u_hAm644gBM-segmented-20261020`：同视频同转录，双方 75 显示单位、宽字素 2、译文倍率 1；另测 Krillinai 65 软目标。保留失败、中间版本和正式冷启动的独立日志，不把半片结果或缓存复跑当成完整成本。日、西、中文另用有出处的真实人类文本摘录；时间为人工验证数据，不能冒充这些语言的视频/ASR 测试。

## 上轮验收（v6历史结果）

本轮未通过质量与成本验收，默认保持 `legacy`。75 版为 75,756 token，VideoLingo 为 58,681；65 版首次失败与恢复合计 149,005 token，不能当成单次成功冷启动。两版均满足双侧单行不超过 75、原文完整覆盖及原文位置时间映射；缓存复跑均为零新增请求，三份 SRT 哈希不变。

独立审查完成不等于译文正确。实测仍有跨段重复、错误术语及口语修正直译，完整 ID 合并候选也可能语义错位；因此不能仅凭 `reviewed` 状态切换默认。完整对照、逐阶段成本与失败证据见基准目录的 `deliverables/REPORT.md`。

## v8 本轮实验

本轮证据目录为 `benchmarks/u_hAm644gBM-quality-20261020`。固定旧草稿先比较表达任务，再单独比较小批次；首测100,306 token未达标，保留其全部消耗；撤回缩批并增加依存边界校验后运行新版原视频与多语言摘录。源文33.8三次模型切口被拒后，增加依存树优先选择并在相同阶段协议上恢复，仅处理未完成项；失败与恢复全部计入，VideoLingo 和旧版本复用原成品。保留全部请求、失败和开发尝试成本，最终质量与成本见该目录的交付报告。默认仍为 `legacy`。

## v9/v10 自然度实验

证据目录为 `benchmarks/u_hAm644gBM-naturalness-20261020`。先冻结相同草稿，对照原表达、精简任务、不提供草稿、母语编辑和参考项目原始表达模板；精简或删除草稿未证明稳定改善，采用具体逐行编辑表继续整片验证。基准中包含相同视频、中英最终成品、旧成品只读复用、多语言摘录和完整请求记账。默认保持 `legacy`；最终质量与成本以该目录实测报告为准，不能由单元测试或审查通过推定自然度达标。

v9整片首测在局部重复修复上失败：审查虽明确指出相邻两条的重复，模型仍逐条改写同一个坏边界。v10将同一条审查明确指出的多个ID组成最小连续编辑块，重叠块合并、互不相连的问题块分别保留；原文字节位置和来源ID不变。后续重拆保存并排除该局部块刚失败的源切口，不能重新返回同一组合；无本地候选时将失败切口及原因交给LLM，返回结果仍需验证。这个合并以审查的显式ID为依据，不从空译文猜合并。修复合并只生成未审候选，超75时仍须重拆和再次核验。

v10首测另发现审查误报：对完整句中已有谓语的译文声称缺谓语，或要求将源语口语改口重复翻译。v11按完整说话意图检查独立命题，允许合并废弃开头、一般被动的隐含主体和相邻句共同语法成分；文风偏好不作为强制重译理由，实际语法、理解及含义错误仍应报告。另逐父句核对行动者、听话人、所有者与个人例证，防止把对听众的说明改成说话人自身经历。保存的正确改写和真实重复、人称错误用于开发对照，不能把这一小组通过称为稳定审查准确率。审查及修复仍保留，未用删除审核来降低消耗。Prompt变更更新为v11缓存指纹，旧版本不冒充本版冷启动。

v11在新目录一次完成同片70父句、134条中英字幕：79,116 token、192.682秒。助手逐条审阅估分为自然度8.0、总分8.2，上轮为7.4/8.1，参考为8.6/8.3；非盲评或金标准。改善了若干直译搭配与对齐语序，但12、39、51仍有重复，54书名、67语义仍不稳，不能宣称全面达标。双侧单行≤75、0重叠、源文覆盖和位置时间对应检查通过；五组缓存复跑0请求、20份SRT哈希不变。日/西/繁中与未参与表达对照的英语文本回归结构通过，仍有数量弱化和跨cue信息提前，不能把结构检查当多语言语义验收。全部开发/失败/回归模型投入323,785 token分列留存，默认继续legacy；完整成品、评分与失败账单见该目录deliverables/REPORT.md。

## 运行优化短片实测

2026-10-20使用用户指定的 `iKknJnHwQt8`（146秒、279源词），证据目录为工作区 `benchmarks/iKknJnHwQt8-runtime-20261020` 及其 `-r2`、`-r3` 目录。三轮均为独立无翻译缓存的新目录，共用英文自动字幕和词时间，不测下载、ASR、配音。相同模型、各自并发3、双侧75，翻译Prompt与运行优化前一致，保留独立审查。

Krillinai三轮50.634、54.972、50.741秒；VideoLingo134.594、81.723、63.002秒。两边首次程序运行均3/3完成；VL首轮含三次上游SSL失败及重试，不能把该轮差距当正常速度。两轮没有HTTP失败时K也均更快。三轮耗时中位数50.741对81.723秒，K少37.9%；token中位数20,366对17,469，K仍高16.6%，尚未消除全部成本差距。

三轮K各24父句全部reviewed、41条中英字幕，通过原文覆盖、字节位置、词时间映射、双侧≤75、无重叠及三份标准SRT一致检查。代理关闭后分别恢复，9份SRT哈希不变，无模型完成事件和接口连接错误；定向race故障回归及相关pipeline集成测试通过。此前长视频性能复测按用户改样本要求取消，部分消耗单列保留，不能当失败或完整速度结果。短片与故障回归不能证明长视频、所有语言永久稳定，也不构成本轮新质量盲评分；默认仍为legacy，完整边界和记录见新目录deliverables/REPORT.md。
